# 交互设计：一本台账怎么用

> 按 `frontend-design` 的流程做：先定题材 → 定 token 与版式 → 设计**人与它的动作序列** →
> 自评 → 落地。视觉方向见 `VISUAL-DIRECTION.md`；这份只管**怎么用**。

## 一、隐喻定了，交互就跟着定

如果这个产品是一本台账，那么它的动作只有四个词：

**翻**（看有哪几行）· **签**（表态）· **转**（交给下一手）· **查**（追溯依据）

所有页面都由这四个词长出来。凡是不能用这四个词解释的交互，就不该存在。

## 二、主循环：一次「签」

```
① 打开            → ② 看到「待你签 3」       → ③ 点其中一行
   （不滚动、不点菜单）    （第一屏第一行）            （展开成一张单）
                                                    ↓
⑥ 这一行消失，下一手出现  ← ⑤ 盖章，留痕        ← ④ 写一句为什么
   （不用刷新页面）           （谁、何时、依据）        （可不写）
```

**每一步的判据**：这一步之后，人的疑问少了一个。六步对应六个问题：
*有我的事吗 → 几件 → 是哪件 → 凭什么批 → 批了会怎样 → 接下来谁办。*

## 三、四个动作的具体交互

### 翻：翻的是行，不是页

- 台账行**不需要点开就能读到关键信息**：谁、什么事、什么时候。
- 点行 = 展开**附页**（右侧抽屉），不是跳页。跳页会丢上下文，而"上下文"正是这个产品卖的东西。
- 键盘：`j/k` 上下移，`Enter` 展开，`Esc` 合上。

### 签：一次点击 + 一个可选理由

- 「签」不弹确认框 —— 它已经是最终动作，再问一遍是把责任推回给用户。
- 「不签」**必须给理由**：不是流程洁癖，是因为下一手需要知道为什么被退回。
- 签完，那一行**原地变成回执**（谁、何时、依据哪条），不消失、不刷新 —— 人要看得到自己刚做的事。

### 转：转是唯一会"离开手"的动作

- 转必须**指定下一手**，不能"交给系统"。
- 转完的画面要说清：**现在球在谁手上**，以及**他不办会怎样**（超期规则）。

### 查：从数字进，从原文出

- 任何数字，`hover` 出**它怎么算的**，`点击` 进**原文那一行**。
- 追溯永远终止在 `文件:行号`。终止在"另一个页面"就不算追溯。

## 四、三个状态，每种都有台词

| 状态 | 台词（界面上的字） | 动作 |
|---|---|---|
| 空 | 「现在没有等你签的字。」+ 一句"最近一次签字是什么时候" | 无（不给假 CTA） |
| 载入 | 骨架，但**行数固定**（3 行）—— 高度不跳 | — |
| 错 | 「读不到：<一句人话>」+「重试」+「去修真相源」 | 可点 |

错的状态必须**说清是谁的错**：真相源坏了、服务没起、还是你没权限。三种话不一样。

## 五、版式规则（交互的物理层）

| 规则 | 理由 |
|---|---|
| 一行一条，横线分隔，不用卡片 | 卡片让人以为每条都是独立对象；台账里它们是同一本账的行 |
| 字段名左、值右、数字等宽 | 扫读时眼睛只走一条竖线 |
| 红只在"等你签"处出现 | 红是章，不是报警 |
| 一次只让一处动 | 动效是"这件事变了"，不是装饰 |
| 页内不跳页 | 跳页丢上下文；上下文是这个产品的核心 |

## 六、自评（skill 要求：先critique 再交）

**会被质疑的四处：**

1. **不做确认框** —— 有人会担心误点。答：签的反面（不签）要求理由，误点成本是"多写一句"，
   而确认框的成本是**每次都要多点一下**。选前者。
2. **附页而非新页** —— 深链会变难。答：附页也给 URL（`#/approvals?open=<id>`），可以发给别人。
3. **红色只给待签** —— 失败了怎么办？答：失败用**文字加灰线**，并在行内直接写"没成功：原因"。
   红色留给"需要你"这一个意思。
4. **不用卡片** —— 会不会太素？答：素是刻意的。**只有一处有表情**（那枚章），其余安静。

## 七、落地顺序

1. **待批台账行**（本轮已做：字段左、值右、横线）← 主循环的核心
2. 点行 → 右侧附页（复用现有抽屉）
3. 签完原地变回执，不刷新
4. 键盘 `j/k/Enter/Esc`
5. 其余页按同一套台账规则重排（项目、成员、审计）

## 八、一句话

**这个产品的交互只有一个目的：让"谁该动手"这件事，在任何一屏上都看得见、点得到、留得下。**
