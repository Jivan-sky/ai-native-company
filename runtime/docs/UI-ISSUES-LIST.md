## A. 顶栏与控件

| # | 问题 | 证据 | 要怎么改 |

| A1 | 上面那条做了很圆的 R 角，**搜索框却是直角**，同一排里两种语言 | `.cmd-btn` 是 `10px`，外层容器无圆角；顶栏自身没有统一圆角 | 顶栏内所有控件统一 8–10px；顶栏容器本身不做圆角（它是通栏），**别一半圆一半方** |

## D. 我做错的方法

| # | 问题 | 说明 |
|---|---|---|
| D1 | **只验功能，没当用户走一遍** | 每轮我用断言检查"有没有 h1、有没有重叠"，但没真的像人一样：打开侧栏、读目录、点两个按钮、滚一屏。所以"密集、看不懂、连成一片"这类问题，断言永远抓不到。 |
| D2 | 同一个坑反复踩 | 宽度写死 → 弹回 → 又写死 padding → 盖住内容。根因：**改一个会变的值，却没让依赖它的东西跟着变**。 |
| D3 | 我一直在"响应你指出的点" | 没有一次是自己走完一屏、把不顺的地方列出来。这份清单是被迫才有的。 |
