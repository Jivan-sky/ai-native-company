# 看板 v2：设计简报

## 十秒脚本

早上打开，10 秒内要回答三问：**有没有事 / 谁在等 / 我下一步做什么**。
答不出来的元素，删掉。第一屏只放「一句结论 + 三个数 + 要我做」。

## 结构

- **一句结论**：四态（正常 / 提醒 / 卡点 / 读不到），颜色只表达状态。
- **三个数**：bot 红 / 待批 / 项目（与左栏用**同一个词**，否则第一屏自相矛盾）。
- **三栏**：要我做（按原因归并的卡点 + 待批）、东西在哪（成员/域/项目）、出过什么事（最近三条）。
- 细节进各自的页；这一屏不堆表。

## Tokens（`styles/v2.css`）

- 间距 5 档（4/8/12/20/32），字号 5 档（11/12/14/18/28）；
- 语义色：`--ok / --warn / --block / --unknown`，不做装饰色；
- 基调沿用：暖白纸感、低饱和、安静。

## 状态

加载 / 空 / 被拒 / 过期 / 部分失败——五种都要有**人话**，不许留白。
「读不到」必须与「没事」区分开（第一屏的结论就是按这个写的）。

## 已知的坑（踩过）

- 运行态的档位词是 `ok / warn / fail / unwired`，不是 `red`；弄错会让结论与左栏打架。
- 同一原因的多个卡点要归并成一条；三条一模一样的行是设计偷懒。

## 这一轮学到的（别再踩）
- `.vt td { white-space: nowrap }` 会把整张表顶出容器（六列只剩两列）。只给短标记 nowrap。
- `localTime()` 是 `toLocaleString()`，位数不固定（8 号 vs 11 号）；**不要切字符串**，自己拼。
- `var(--x, #hex)` 的兜底色在深色主题里就是那个颜色：`.tabs` 原来用了 `.v2` 里的变量，
  而标签栏不在 `.v2` 里 —— 深色下会黑得看不见。跨作用域的组件只吃 `:root` 上的变量。
- 无头 Chrome 的 `--user-data-dir` 要每次唯一，否则会连到上一次残留的浏览器，截到旧页面。
