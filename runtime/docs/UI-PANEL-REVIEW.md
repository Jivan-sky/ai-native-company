## 一、四个人独立指向同一处的（可信度最高）

### 1. 一屏之内没有焦点

| 谁 | 怎么说的 |
|---|---|
| 老板 | 5 秒测试失败：「最大字号是红字『有 3 个 bot 回不了话』，讲的是系统自己，不是我的生意」 |
| 品牌 | 「红一屏只准出现一次」；「满屏 12px 灰字解释」 |
| 我量的 | 每页 **60–126 个元素都是 14px**；小节标题与正文同号（14px/600）；级差只有 2 倍 |

**这不是审美偏好，是可测量的结构缺失**：字号系统里没有层级，读者只能靠位置猜。

### 2. 它在讲自己，不在讲客户的生意

老板的原话最狠：**「9 屏里 7 屏在讲系统自己（bot / gateway / socket / job / HTTP 200），不讲业务（订单 / 客户 / 回款）。」**

一线的是同一件事的另一面：**「bot 红了，点不动，只能开终端」**。

### 3. 该人拍板的地方，界面没有入口

| 评审判定 | 证据 |
|---|---|
| 信息架构 | 「决策没有家」：审批 / 结账 / 授权签发散在三页，身份靠手填 |
| 一线 | 列出 **10 个动作**（起网关、交接、验收、升级、应用批准、作业跑一次、告警推送、数据分级、就绪基准、新增客户、审计记一笔、沉淀成技能）**全部零入口** |
| 品牌 | 「可干预 = 0：九张截图里没有一个『撤回 / 停止 / 回滚』」 |

**结论一致：我们的界面只让人"看"，没让人"管"。**

### 4. 最强的能力全埋在命令行里

品牌那句说得准：

> 界面能撑住的一句：**每个 bot 干的每件事，你都能点回到一个批准人、一个时间戳、一行原文。**
> 完全看不出、但最该上屏的一句：**AI 动你数据之前，先把「要动什么、动了会怎样、怎么退回来」摊在你面前，等你点头。**

我们做了预演、diff、读回验证、备份、原子落盘、三档可逆 —— **看板上一个字都没有。**

## 二、几个人各自独有的、但同样致命的

**信息架构师**（结构性，最难补）：
- 导航有**三套**（左栏 9 项 + 顶部 5 项 + 19 个子 tab），且顶部「审计」点下去静默落到「记录·时间线」，顶部无选中态
- 角色下拉是 localStorage，只隐藏 tab，**不参与后端判定** —— 界面在演一个它没有的权限系统
- 接入页文案「看板是只读的，它没有写口」与同页「生效（写盘）」按钮**互相打脸**（已修）
- 建议：**9 页 → 5 页 + 一个决策抽屉**。审批/结账/授权签发全收进抽屉 —— 「打断不是目的地」

**一线负责人**：
- 20 个项目要滚 10 屏、8 个 agent 要点 8 次；缺项目矩阵与 agent 矩阵
- 「每日完成 33%」的分子分母都是 agent 自己写的，**这个数他签不了字**

**品牌**：
- 封面是 AI 插画（水下人像 + 水母 + 玻璃拟态）+「四层两纵切」，像艺术项目不像能装进机房的系统
- 可核算 = 0：没有成本、时长、影响面
- 「谁在点」靠手打英文 slug，还提示「会写进文件名」——**这不是身份，是自证**

## 三、按什么顺序改

### 阶段 0 · 止血（已完成 / 今天）

| 项 | 状态 |
|---|---|
| 本机绝对路径上屏 | ✅ 已修（scrub 现在覆盖 vault / data / cwd 三个根） |
| 接入页「没有写口」的假话 | ✅ 已修（改成如实描述写盘事务的六步顺序） |
| 每页语义 h1 | ✅ 已修 |

### 阶段 1 · 立骨架（先做，因为后面所有页都吃它）

1. **换底色**：奶油暖底 → 中性近白/极浅灰。暖底会把每张卖出去的截图染黄。
2. **主色换石墨/深墨**，绿只做「通过」，红一屏一次。
3. **字号收到 5 档**：12 / 14 / 20 / 28 / 36（现在 22 种）。解释性文字降到抽屉，不许再靠小字承载信息。
4. **圆角收到 3 档** 6 / 10 / 14；**50 处 box-shadow 全部删掉**，边框与阴影二选一。
5. **112 个硬编码色值全部走 token**；**数字全局 tabular-nums**；日期统一一种写法。
6. **删装饰**：三层 radial 渐变、面板渐变、网格纹理、金色 orb、LIVE 呼吸点。
7. **删重复导航**：顶部 5 个 tab 与左栏重复，删掉，首屏立刻多出 44px。
8. **选中态只留一种语言**：2px 左条 + 字重。

验收：总览页首屏 5 秒内能说出三件事，且不靠读解释文字。

### 阶段 2 · 决策有家

6. 顶部/左栏二选一，砍掉重复导航；`#/audit` 不再静默降级。
7. **决策抽屉**：待批、结账、授权签发、应用审批共用一个抽屉；身份从"手填"改成"选人"（下拉当前成员），手填只作为兜底。
8. 每个写按钮旁边写明「会发生什么、怎么退回」。

### 阶段 3 · 把能力放出来

9. 一线列的那 10 个动作，按「系统 / 记录 / 运行 / 数据 / 资产」逐页补入口，全部走已有 API，不新造后端。
10. 补三根信任柱：**可追溯**（已有，提升到每页可点）、**可干预**（暂停/回滚/重跑）、**可核算**（成本一栏）。

### 阶段 4 · 示例数据

11. 换一套连贯的示例组织（不要 acme/demo/hello 这种占位词），并标明「示例组织」。

## 四之二、设计总监那份（最狠的一份，全是可执行数字）

**判断：工程与状态诚实是产品级，视觉系统仍是组件库演示。**
一号位 10 秒内指不出「我该点哪里」——总览首屏 **0 个任务动作按钮**。

### 它是把"淡"数出来的

| 测量 | 现状 | 应该 |
|---|---|---|
| 字号种类 | **22 种**（8.5–36px） | 5 档：12 / 14 / 20 / 28 / 36 |
| 圆角值 | **18 种** | 3 档：6 / 10 / 14 |
| box-shadow | **50 处** | 0 处（边框与阴影二选一） |
| 硬编码色值 | **112 个** | 全部走 token |
| 卡片标题/正文 | 14/12 = **1.17 倍** | 至少 1.4 倍 |
| 最大/最小字 | 28/12 = **2.3 倍** | 3 倍以上 |
| 首屏被导航吃掉 | topbar 64 + tabs 44 + subtabs 61 = **223/600 = 37%** | 删掉重复的顶部 tabs |
| 红色出现次数 | **一屏 10 次以上**（结论/卡点/柱子/100% 时间进度/pill 边框） | 一屏一次 |
| 选中态 | **4 种视觉语言**（金左条/米色底/2px 黑框/下划线加粗） | 只留「2px 左条 + 字重」 |
| 卡片边框对比 | 1.15:1（卡面 vs 卡底 1.18:1） | 分块靠留白，不靠猜 |

**并且它纠正了我自己的诊断**：

> 你们把「淡」归给密度会越改越灰；缺的是**层级和动作落点**。

还指出三个我没想到的：

- `page-head.no-title` 删掉 h1 后，**全站最大字号只有 14px** —— 我做的"标题短句化"实际变成了"没有标题"
- 截图实际是 **1258×600**，1280 断点已把三栏降成两栏 —— **设计稿在真机上没出现过**
- 右下角悬浮球在 1258×600 下**压住了「要我做」那行的 pill**
