# 视觉方向：把它做成一本「台账」，不是一套 SaaS 卡片

> 用 `frontend-design`（Claude 官方 marketplace 的视觉设计 skill）审我们自己。
> 它的破绽清单里，我们中了至少四条 —— 这份文件是按它要求的流程重做的设计与取舍。

## 一、先认账：我们中了哪些「AI 生成」破绽

| skill 列的破绽 | 我们 | 证据（代码里数出来的） |
|---|---|---|
| 暖奶油底 + 高对比衬线大标题 + 陶土色 accent | 中了（上一版就是米黄） | `--bg: #f6f1e4` |
| SaaS 卡片套件：内容切成同样的圆角卡片、一个圆角用到底、同一层软灰阴影 | 中了 | 7 处同一个 `--radius`，所有卡片同款阴影 |
| 模板外壳：全大写 eyebrow、`A · B · C` 中间点、等宽字体做小标签 | 中得很彻底 | 9 处 `uppercase`、**49 处** `" · "`、**55 处** `var(--mono)` |

这不是"风格问题"，是**没做选择**：这些默认值在任何项目上都成立，所以它不能替这个产品说话。

## 二、这个产品的题材是什么（选型的依据）

ANC 不是"数据看板"，它管的是**一件事在人与人之间怎么交出去、谁签的字、留了什么痕**。
它用的词本来就是中国公司里的词：交接、签收、台账、留痕、岗位、待签。

那视觉就该来自这套材料，而不是来自 SaaS 模板。这条方向的落点：

**它应该像一本做得很讲究的台账**——横线、编号、签章位、字段名在左、值在右。
不是"把内容切成一堆一样的卡片"。

## 三、设计方案（4 个 token 系统 + 一条原则）

### 颜色

| 名字 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f7f8fa` | 底。冷灰白，像纸不像布 |
| `--ink` | `#14161a` | 正文。真正的近黑，不用 `#0B0B0B` 那种"假黑" |
| `--rule` | `#dfe3ea` | 横线。**结构信息的载体，全站主要的分隔手段** |
| `--seal` | `#c03027` | **签章红，全站只表示一件事：等你签** |
| `--accent` | `#3b5bdb` | 品牌靛，只表示"可点/当前" |

关键取舍：**红色从"卡点/失败"改成"待签"**。中国单据里红是章、是催办，不是"报错"。
失败改用 `--rule` + 文字说明 —— 于是红色一屏最多出现一次，而且每次都指向"需要你"。

### 字体

- 一套无衬线（系统中文：PingFang SC / 思源黑体）承担全部界面文字。
- 数字用等宽**但只在数值列**，不用它做小标签（那是模板味）。
- 字号五档：12 / 13.5 / 16 / 22 / 32。标题用 22，不用 32 去"撑场面"。

### 版式

```
┌────────────────────────────────────────────┐
│ 待你签 · 3                          2026-11-14 │  ← 一行，左对齐，无 eyebrow
├────────────────────────────────────────────┤
│ 提请          谁           事                 │  ← 字段名在左，值在右（单据感）
│ ──────────────────────────────────────────  │
│ 王倩   交付   把 Q3 的验收口径改成按批次      │  ← 横线分隔，不是卡片
│ 李默   采购   这笔付款超预算，要你放行        │
└────────────────────────────────────────────┘
```

- **主体是横线台账**，不是一个一个盒子。卡片只留给"确实是一个整体"的东西。
- 左对齐，数字右对齐；字段名用 12px 灰，值用 13.5px 墨色。
- 不用 `01 / 02 / 03` 编号——这里的内容不是序列。

### 原则

**只有一处是有表情的，其余全部安静。**
这一处就是那条红：`待你签`。除此之外不发光、不大字、不渐变。

## 四、这一轮改了什么（已落地）

1. **删掉全大写 eyebrow 与字母间距** —— 它们在任何产品上都能出现，是模板外壳
2. **引入签章红 `--seal`**，只用于"等你签"这一类，卡点/失败改回文字与灰线
3. **待批列表改成横线台账**（字段左、值右、行间一条线），不再是一张张卡片
4. 中间点 `·` 收敛：只在"确实是并列的两件事"时用

## 五、还没做（下一步）

- 全站 `·` 的清理（49 处里大部分可以改成空格或干脆不写）
- 等宽字体只保留数值列（55 处里大部分用在标签上）
- 业务模块格：现在是卡片，应该改成一行一行的台账

## 六、为什么这次不是"再换一套配色"

skill 里那句最该记住的话：**这些特征对某些选题是合理的，但它们是默认值而不是选择，
而且不管什么选题都会出现。** 我们要做的不是"更好看的默认值"，是**为这个题材做一次选择**。
