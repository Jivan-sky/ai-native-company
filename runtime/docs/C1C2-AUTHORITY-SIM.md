# C1 / C2 的三个卡点（以及我在模拟里用的默认值）

> 这三问本来就该由客户拍。现在没有客户，我按「可验证的默认值」先跑一版，
> **每一问都写清：它卡住什么、选项是什么、我默认取哪个、换成你的答案要改哪一处。**
> 不是死胡同 —— 默认值可以先跑，换答案时只动一处。

## 卡点一：谁是**受托签发人**（C1 · #76）

**卡住什么**：第一笔根授权（「谁有权给第一个权限」）没有来源，后面所有委派都是空中楼阁。
SPEC 不允许「自称 owner 就行」，也不允许「部署者自动获得权限」。

**选项**

| 选项 | 含义 | 代价 |
|---|---|---|
| A. 客户书面委任某个人（`member:alice`）为受托人 | 最贴近真实治理：出了事有人签字 | 需要一个「书面确认」的落地形态 |
| B. 客户 IT 负责人这个**岗位**为受托人 | 人事变动不失效 | 岗位复用时旧授权会漏给新人（A3 明确要防） |
| C. 首个部署者自动成为受托人 | 零成本 | 等于「谁装谁老大」，审计上说不通 |

**我默认取 A**，并在权威源里写死一个名字：

```yaml
# <vault>/authority.md
issuer: member:alice      # 受托签发人（模拟：客户 IT 负责人书面委任）
delegation: 客户 IT 负责人书面确认（模拟件，见 docs/C1C2-AUTHORITY-SIM.md）
```

**换成你的答案要改哪**：只改 `authority.md` 的 `issuer:` 一行。判定读的是这个字段，不是代码里的名字。

## 卡点二：根授权与撤权的**权威写口**在哪（C1/C2 · #76 #77）

**卡住什么**：撤权要「即时生效」，但事实是经 Git 周期同步的副本。没有唯一权威写口，
副本永远无法证明自己看到的是最新版本 —— 于是「已撤权」这件事没法判定。

**选项**

| 选项 | 含义 | 代价 |
|---|---|---|
| A. `authority.md` 的 `version` 单调递增，提交即权威 | 与「SPEC 是唯一真相源」一致：Git 就是发布总线 | 「提交即生效」要求写口唯一（多人同时提交要靠 Git 顺序） |
| B. 独立的授权发布记录（带前序哈希的链） | 能证明顺序与完整性 | 多一套机制，还要人维护 |
| C. 画板/飞书审批单为准 | 贴近客户流程 | 自动化程度低，抓不到「同一秒谁先」 |

**我默认取 A**：`authority.md` 里一个单调的 `version`，撤回事件记在同一个文件里、带 `version`。
判定时读到的版本就是权威版本；读不到就返回「无法判定」，不放行。

**换成你的答案要改哪**：换 `internal/org/authority.go` 里的 `LoadAuthority`（只这一处读权威源）。

## 卡点三：撤权的**生效点**按什么认（C2 · #77）

**卡住什么**：动作发生在「撤权提交」与「副本拉到」之间时，该按哪一版判？

**选项**

| 选项 | 含义 | 代价 |
|---|---|---|
| A. `authority.md` 的 `version` 推进即生效 | 简单、可解释：看版本号 | 副本拉取有延迟时，窗口内的动作会被判成「按旧版允许」 |
| B. 必须等到「指定引用推进到验证过的修订」 | 严格 | 需要发布流程配合 |
| C. 撤权带时间戳，按服务端时钟判 | 直观 | 时钟不可信；且副本根本不知道有新时间戳 |

**我默认取 A + 一条硬规矩**：**本地无法证明自己是最新版本时，返回「无法判定」而不是放行。**
这条比选哪个更重要 —— 它让「不知道」永远不会变成「允许」。

**换成你的答案要改哪**：`authority.go` 的 `Exercise` 里那个版本比较。

## 模拟里怎么用（不依赖真实组织）

| 角色 | 谁 | 权限来源 |
|---|---|---|
| 受托签发人 | `member:alice`（超管） | `authority.md` 的 `issuer` |
| 管理员 | `member:bob` | alice 签给他的域授权（`issued_by: member:alice`） |
| 普通成员 | `member:carol` | bob 转授给她的更窄一条（`parent:` 指回 bob 那条） |

三者都在 `runtime/.devbox/macos/acme2` 这个沙箱 vault 里，**不是真组织**。
要验「撤权」「到期」「离职」，改 `authority.md` 的 `version` 与 `revoked:` 即可 —— 不用等任何人。
