# 指标合同（v3 · 框架版）

> 这份表的用途只有一个：**屏幕上每个数字，都能在这里查到它是怎么算的、从哪来、什么时候算的、哪里会错。**
> 查不到的数字不许上屏。这一条是 PLAN-v3 §1 那个押注的落地方式。

## 计数规则

- **一个「数」= 一个独立的指标位**。一条分布条（如审计的四档）算 **1** 个，不按格子数算。
- 明细行（表格里的一行）不算数字，它自己就是原始记录。
- 合计预算 **≤ 24**。当前：**13**，见下表。
- 每个数都必须能点开，弹出它的「最后一行来源」（`file:line`）与这份合同的那一行。

## 验证命令（不许只看图）

```bash
# 每日 done —— 曲线上的每个点都必须与这里逐日相等
cat timeline/*.jsonl | jq -r '.at[0:10] + "\t" + .status' | sort | uniq -c

# 达成率
cat timeline/*.jsonl | jq -r '[.at[0:10], .status] | @tsv' \
  | awk -F'\t' '{if($2=="done")d[$1]++; else if($2=="failed")f[$1]++} END{for(k in d) printf "%s done=%d failed=%d\n", k, d[k], f[k]}'
```

当前真数据的答案（2026-11-11 采）：`11-10 done=5 failed=10`、`11-11 done=3`、`11-12 done=3`，共 22 条。
**只有三天** —— 所以这一版画出来是三个点，不是趋势线；屏上必须写「仅三天，仅供趋势」。
